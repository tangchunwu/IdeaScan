

# IdeaScan 下一阶段产品优化计划

## 现状总结

所有基础优化（19项）和竞品对标（5个Phase）已全部完成。产品当前具备：验证引擎、报告系统、创投圈AI辩论、Discover热点雷达、MVP生成器、历史记录管理、PDF导出、分享机制。

定价页存在但付费功能未打通（专业版CTA指向 `#`）。配额系统仅基于免费次数。

---

## 优化方向规划

### 方向一：用户留存与转化闭环

| 优化项 | 描述 | 优先级 |
|--------|------|--------|
| **邮件通知系统** | 验证完成后发送邮件通知（含报告摘要 + 链接），减少用户流失 | 高 |
| **报告过期提醒** | 对30天未回访的报告发邮件提醒，引导用户回来查看或重新验证 | 中 |
| **验证历史统计仪表盘** | History页顶部增加统计卡片：总验证数、平均分、最高分、本月趋势折线图 | 高 |
| **成就/徽章系统** | 完成首次验证、分享报告、高分验证等里程碑徽章，提升用户参与感 | 低 |

### 方向二：报告数据可视化增强

| 优化项 | 描述 | 优先级 |
|--------|------|--------|
| **趋势时间线图** | 在Overview Tab增加关键词搜索量随时间变化的趋势图（利用已有weeklyTrend数据） | 高 |
| **竞品矩阵散点图** | 竞品Tab增加二维散点图（X=相关度, Y=竞争强度），直观展示竞争格局 | 中 |
| **情感分析词云** | Sentiment Tab增加关键词词云，高频正面/负面词可视化 | 中 |
| **报告对比视图增强** | Compare页支持两份报告雷达图叠加对比，差异高亮 | 低 |

### 方向三：新功能探索

| 优化项 | 描述 | 优先级 |
|--------|------|--------|
| **一键重新分析** | 报告页增加"用最新数据重新分析"按钮，调用re-analyze接口刷新报告（已有后端，前端入口不明显） | 高 |
| **想法收藏夹** | 用户可在Discover页收藏感兴趣的热点话题，后续一键导入验证 | 中 |
| **报告评论/笔记** | 用户可在报告上添加私人笔记，记录自己的思考和行动计划 | 中 |
| **周报摘要** | 每周自动生成用户的验证活动周报（验证了哪些想法、分数趋势、推荐行动） | 低 |
| **协作分享** | 支持邀请团队成员查看和评论报告（需新增权限模型） | 低 |

### 方向四：增长与SEO

| 优化项 | 描述 | 优先级 |
|--------|------|--------|
| **公开报告Gallery** | 精选高质量报告组成公开展示页，吸引搜索流量 | 高 |
| **博客/案例页** | 静态内容页展示验证案例，提升SEO覆盖面 | 中 |
| **推荐系统** | 分享报告时生成邀请码，被邀请人注册送额外验证次数 | 中 |

## 技术要点

- **历史统计仪表盘**: 纯前端计算，从已有 `validations` 数据聚合，用 recharts 渲染
- **趋势时间线图**: 已有 `TrendTimelineChart.tsx` 组件，需在 Overview Tab 中集成
- **邮件通知**: 需新建 Edge Function + 数据库触发器，使用 Resend 或类似服务
- **公开Gallery**: 新建路由 `/gallery`，查询 `is_public=true` 的报告，展示精选卡片
- **竞品散点图**: 用 recharts ScatterChart，数据从 `competitorRows` 映射
