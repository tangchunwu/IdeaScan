

# 笔记与分享功能优化计划

## 当前问题

从截图和代码中发现以下体验问题：

### 笔记 (ReportNotes)
1. **无自动保存** — 用户可能忘记点保存导致丢失内容
2. **无快捷键** — 没有 Ctrl/Cmd+S 保存支持
3. **无字数统计** — 用户无法知道写了多少
4. **Textarea 高度偏小** — 100px 对于认真记录笔记不够用

### 协作分享 (CollaboratorPanel)
5. **无邮箱格式校验** — 用户输入非邮箱格式也能提交，会导致后端错误
6. **权限显示单一** — 只有 "view" 权限，但 UI 未说明

### 分享卡片 (ShareCard)
7. **品牌名错误** — Footer 显示 "IdeaValidator.ai" 而非 "IdeaScan"
8. **缺少链接分享** — 只能下载图片，没有复制分享链接功能

---

## 优化计划

### Task 1: 笔记增加自动保存 + 快捷键 + 字数统计
- 添加 2 秒防抖自动保存（内容变化后自动触发）
- 支持 Ctrl/Cmd+S 快捷键保存
- 底部显示字数统计
- 增大默认高度到 160px

### Task 2: 协作分享增加邮箱校验
- 添加简单的邮箱格式正则校验
- 无效格式时禁用提交按钮并显示提示

### Task 3: 修复 ShareCard 品牌名 + 增加链接分享
- 将 "IdeaValidator.ai" 改为 "IdeaScan"
- 在分享 Tab 中增加"复制分享链接"按钮，调用 `get-shared-report` 边缘函数生成 share_token

---

## 技术要点
- 自动保存使用 `useEffect` + `setTimeout` 防抖，避免频繁写库
- 邮箱校验使用简单正则，无需引入额外库
- 链接分享复用已有的 `get-shared-report` 边缘函数 POST 接口
- 预计修改 3 个文件
