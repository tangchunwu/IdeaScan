

# OpenClaw 页面布局修复

## 问题分析

从截图可以看到几个布局问题：
1. **Tabs 位置悬浮在页面中间**，与 Navbar 之间有大量空白，且 TabsList 居中显示看起来不协调
2. **聊天容器缺少页面标题**，直接从 Tabs 开始，缺少上下文
3. **空状态区域** 没有很好地填充空间

## 修复方案

### 修改 `src/pages/OpenClaw.tsx`
- 添加页面标题区域（标题 + 简短描述）
- 将 TabsList 左对齐而非居中，与标题对齐
- 调整 `pt-20` 间距，使页面更紧凑
- 聊天容器高度使用更合理的计算值

### 修改 `src/components/openclaw/OpenClawChannel.tsx`
- 空状态（无连接时）增加跳转到设置 Tab 的引导按钮
- 优化空消息状态的垂直居中

共修改 2 个文件，纯 UI 调整，无后端变更。
