
# OpenClaw 对话界面 UI/UX 优化计划

## 现状问题分析
从截图观察：
1. **消息气泡**：用户消息绿色背景不够醒目，AI 消息灰色背景对比度低
2. **头像设计**：圆形带图标的设计较为普通，缺乏个性
3. **顶部栏**：OpenClaw logo + 下拉选择器 + 新对话按钮布局松散
4. **输入区域**：朴素的输入框和发送按钮，缺乏视觉吸引力
5. **空状态**：快捷操作卡片样式简单

## 优化方案

### 1. 消息气泡重设计
| 角色 | 当前 | 优化后 |
|------|------|--------|
| 用户 | 绿色纯色背景 | 渐变背景 (primary gradient)，阴影增强 |
| AI | 灰色低对比度 | 玻璃态背景 + 微妙边框，更好的可读性 |

### 2. 头像升级
- AI 头像：使用渐变背景 + 动画光晕效果（响应时）
- 用户头像：显示用户名首字母或更柔和的图标样式

### 3. 顶部栏精简
- 左侧：Agent 名称（从连接配置读取）
- 右侧：紧凑的连接切换器 + 新对话按钮合并为更精致的操作区

### 4. 输入区域现代化
- 毛玻璃背景
- 发送按钮带悬浮态动画
- 添加快捷操作入口（如上传图片按钮预留位置）

### 5. 打字指示器优化
- 当前三个弹跳圆点 → 更流畅的脉冲动画或 Shimmer 效果

### 6. 空状态重设计
- 更大的图标 + 渐变装饰
- 快捷卡片添加 hover 效果和图标颜色变化

## 文件改动
| 文件 | 改动 |
|------|------|
| `src/components/openclaw/OpenClawChannel.tsx` | 全部 UI 组件样式重构 |

## 预期效果
- 更现代、精致的对话界面
- 用户/AI 消息视觉区分更清晰
- 整体风格与产品其他页面更统一
